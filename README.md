Simple Banking System

A beginner-friendly Java console application that simulates basic banking operations. It allows users to check their account balance, deposit money, and withdraw funds through a simple menu.

Features

* Check account balance
* Deposit money
* Withdraw money
* Validate deposit and withdrawal amounts
* Check for insufficient funds
* Menu-driven interface
* Exit the application

Technologies Used

* Java
* Scanner class for user input
* Conditional statements
* Do-while loop
* Basic arithmetic operations

Getting Started

Prerequisites

* Java Development Kit (JDK) installed
* A code editor such as Visual Studio Code

How to Run

1. Clone this repository:

git clone https://github.com/Amazingayo/simple-banking-system.git

2. Navigate to the project directory:

cd simple-banking-system

3. Compile the Java file:

javac SimpleBankingSystem.java

4. Run the application:

java SimpleBankingSystem

How It Works

The application starts with a balance of ₦50,000. Users can select an option from the menu to check their balance, deposit money, or withdraw money. The program validates transactions and continues displaying the menu until the user chooses to exit.

Project Purpose

This project was created to practise Java fundamentals, including variables, user input, conditional statements, loops, and basic input validation.
